# Battleship_Final_new

Project Title: Star wars battleship - Space Wizards

This is the finished playable battleship game of the team Space Wizards, for Mr. Smintich's ICS4U class' culminating project

If you are reading this, chances are you have already downloaded and unzipped/extracted from the zip file, which was uploaded to the shared drive as per requested
Go to your eclipse, go File --> Import, choose General and import the file containing the unzipped contents as existing projects into workspace

The project should now be ready to run - all sounds and images assets are within the project folder
The main method is located in GameLauncher

The user guide/play instructions are located within the game, and will popup upon request (the "info" button) during the game launch menu or automatically when the game is launched
