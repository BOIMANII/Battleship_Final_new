#Battleship_Final_new<br />
Project Title: Star wars battleship - Space Wizards<br />
This is the finished playable battleship game of the team Space Wizards, for Mr. Smintich's ICS4U class' culminating project<br />
If you are reading this, chances are you have already downloaded and unzipped/extracted from the zip file, which was uploaded to the shared drive as per requested<br />
Go to your eclipse, go File --> Import, choose General and import the file containing the unzipped contents as existing projects into workspace<br />
The project should now be ready to run - all sounds and images assets are within the project folder<br />
The main method is located in GameLauncher<br />
The user guide/play instructions are located within the game, and will popup upon request (the "info" button) during the game launch menu or automatically when the <br />game is launched<br />
One known limitation of this program is the fact that when a save is made in hard mode, then loaded, the ai reverts into simpleAI<br />
